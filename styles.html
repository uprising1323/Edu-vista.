How to Use

  1. Copy the CSS code above
  2. Create a new file named styles.css in your project folder
  3. Paste the CSS code into the file
  4. Link it in all your HTML files by adding this in the <head> section:
<link rel="stylesheet" href="styles.css">

Adding the Chakra Element

Add this code right after the opening <body> tag in each HTML file:

<div class="chakra"></div>
